# Community Code of Conduct

SAMS V2 is a community project. We are committed to a respectful, welcoming environment for contributors and users regardless of experience, identity, background, or viewpoint.

Expected behavior includes constructive feedback, patience with beginners, respectful disagreement, and consideration for people affected by academic software. Harassment, discrimination, personal attacks, doxxing, threats, and unwanted sexual attention are not acceptable.

Maintainers may remove, edit, or reject contributions that violate this code and may restrict participation when needed to protect the community. Report conduct concerns privately to the maintainers using the contact channel published in the repository’s GitHub community settings. Do not include student records or credentials in a report.

This policy applies to project issues, pull requests, discussions, and project-related community spaces.

Before the repository is made public, maintainers should add and monitor a private conduct-report contact route in the repository community settings. Reports should not include student records or credentials.
